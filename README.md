# Spam Classifier

This project uses **DistilBERT** to classify SMS messages as **spam** or **ham**.

## Features
- Fine-tunes DistilBERT on the `sms_spam` dataset from Hugging Face
- Predicts SMS messages as **spam** or **ham**
- Trains and tests in a single Python file (`spam_classifier.py`)
